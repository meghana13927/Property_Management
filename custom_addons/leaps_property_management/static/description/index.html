Manage the complete sale pipeline: Booking → SPA Signed → Completed. Create installment payment plans and track outstanding balances.

PDF Contract Reports

Full Workflow

Step-by-step — from setup to signed contract and beyond

1

Install & Configure

Install the Property Management module and configure the required users, permissions and property settings.

2

Add Amenities

Go to Property Management → Settings → Amenities and Services and create amenities such as parking, gym, swimming pool and security.

3

Create Property Units

Create property units and enter property type, location, specifications, pricing, owner and amenities.

4

Create Rental Contract

Select the property unit, tenant, contract dates and payment terms. Activate the contract and generate invoices.

5

Create Sales Contract

Select the property unit and buyer, enter the agreed price and fees, then progress through Booking → SPA Signed → Completed.

6

Log Maintenance Requests

Create maintenance requests, assign vendors and track progress from New through Completed.

7

Print PDF Contracts

Print professional rental and sales contract PDF documents directly from Odoo.

8

Monitor Dashboard

Use the dashboard to monitor properties, occupancy, revenue, invoices, contracts, maintenance and commissions.

🏠 Rental Flow — Full Walkthrough

From creating a unit to generating invoices

Step 1

Create the Property Unit

  • Go to Property Management → Properties → Property Units
  • Create a new property unit
  • Select Apartment, Villa, Commercial or another property type
  • Enter monthly rent and currency
  • Select the property owner
  • Set the status to Available
Step 2

Create Rental Contract

  • Go to Property Management → Rental → Rental Contracts
  • Select the property unit
  • Select the tenant
  • Enter start and end dates
  • Select payment terms
  • Enter security deposit and administration fee if required
Step 3

Activate the Contract

  • Click Activate
  • Contract changes to Active
  • Property unit changes automatically to Rented
  • Enter Ejar registration information when applicable
Step 4

Generate Invoices

  • Click Generate Invoices
  • Odoo creates invoices according to the payment schedule
  • Each invoice has its own due date
  • Access invoices from the Invoices smart button
  • Confirm and collect payments through Accounting
Step 5 — End of Lease

Expire / Terminate / Renew

  • Expire the contract when it reaches its end date
  • Terminate the contract for early exit
  • Create a new contract when renewing
  • The property unit can return to Available status after expiry or termination
Commission

Add Leasing Commission

  • Go to Property Management → Commissions
  • Create a commission record
  • Link the rental contract
  • Select an agent
  • Enter company commission rate
  • Enter agent share
  • Approve and mark the commission as paid when completed

🏢 Sale Flow + Commission

From listing to ownership transfer with complete commission tracking

Add Unit
→
Booking
→
SPA Signed
→
Completed
→
Commission Paid
Step 1

Create Property Unit for Sale

  • Create the property unit
  • Enter property specifications
  • Enter the sale price
  • Select the owner or seller
  • Set status to Available
Step 2 — Booking

Create Sales Contract

  • Go to Property Management → Sales → Sales Contracts
  • Select the property unit
  • Select the buyer
  • Enter agreed price
  • Enter booking amount
  • Add payment plan installments
  • Click Confirm Booking
Step 3 — SPA

Sign the Sales Agreement

  • Print the sales agreement
  • Complete the signing process
  • Click Sign Sales Agreement
  • Track remaining balance
  • Track installment payments
Step 4 — Transfer

Complete the Sale

  • Receive all required payments
  • Click Mark as Completed
  • Contract changes to Completed
  • Unit changes to Sold
  • Sold units are removed from available inventory
Step 5 — Commission

Record Sales Commission

  • Create a commission record
  • Link the Sales Contract
  • Enter the commission rate
  • Select the agent
  • Enter the agent share
  • Approve the commission
  • Mark the commission as paid
Commission Types

Commission Types

  • 🏠 Leasing Commission
  • 🏢 Management Fee
  • 🔄 Renewal Fee
  • 💰 Collection Bonus
  • 🏆 KPI / Occupancy Bonus
💡 Commission Calculation: Company Commission = Base Amount × Company Rate %   |   Agent Share = Company Commission × Agent Share %   |   VAT can be applied according to configured tax requirements.
